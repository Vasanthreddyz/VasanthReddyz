## 🚀 Projects

### 🚦 Real-Time Traffic Prediction and Control using Image Processing
A smart traffic signal system that detects and counts vehicles from multiple road video feeds using a Haar cascade classifier, then **dynamically allocates green-signal time** to each road in proportion to its traffic density.

- Vehicle detection and counting with OpenCV (grayscale conversion, blurring, cascade detection)
- Virtual counting line to track vehicles crossing a point of interest
- Adaptive signal timing for a 4-road junction based on live vehicle density
- **Tech:** `Python` `OpenCV` `NumPy`
- 🔗 [View repository](https://github.com/Vasanthreddyz/traffic-control-image-processing)

### 🎟️ Event Management System
A full stack web application for managing events, built during my Java Full Stack Development course.

- Create, view, update and delete events (CRUD operations)
- Database-backed storage and a responsive front end
- **Tech:** `Java` `MySQL` `HTML` `CSS`
